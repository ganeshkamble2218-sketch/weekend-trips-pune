# Weekend Trips Pune - 19 Seat System

This is a standalone 19-seat selection component.

## Files
- index.html - demo booking page
- style.css - seat layout styling
- script.js - seat selection logic

## Use for every trip
Open the page with a trip name, for example:
index.html?trip=Kaas%20Pathar
index.html?trip=Kokan
index.html?trip=Mahabaleshwar

In `script.js`, set booked seats for each trip:
bookedSeats: [2, 7, 15]

## Important
This ZIP is a reusable seat component/demo. It does not automatically merge with an existing GitHub project or payment/database system. To integrate it into your existing website, copy the HTML/CSS/JS into the relevant booking page/component and connect the Continue button to your existing passenger/payment flow.
